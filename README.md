# 考試計時器

這是一個柔和淺色、左右分欄的監考投影頁面。**雙擊 `index.html` 即可使用**；所有樣式、程式、圖形都已內嵌，不需要安裝、不需要後端、不載入外部字型或 CDN。

## 模板與考試資訊

設定中有 **Calc Exam**、**Calc Quiz**、**清空**三個按鈕。選擇模板只替換草稿，必須按「套用設定」才影響投影。

- **Calc Exam**：保留「微積分1 期中考試」、08:45 入場、09:00–11:30、09:40 可交卷等預設。
- **Calc Quiz**：「微積分1 小考」、17:30–18:20，17:27 考前準備、18:00 提醒剩20分鐘、18:15 最後五分鐘，沒有獨立入場、背包放前面或廁所限制；考前不要求閱讀封面等候宣布或擺放學生證，結束後也不要求留座等候清點。
- **清空**：清除考試資訊、規則與選用時間節點，產生空白草稿。必須填寫考試名稱、日期、開始時間及長度才能套用；完全空白會被阻止。未新增階段時，仍會依基本時程顯示開始／結束狀態。

班別、考場、授課老師、大題數與人數都保留在設定中，直接勾選對應項目即可編輯並放到主畫面。未勾選時欄位呈灰色停用，內容保留。Exam 預設勾選；Quiz 預設不勾選考場、老師、大題數與人數，但可自行開啟。老師未填且已勾選時顯示「未設定」；大題數與人數未填時不顯示，數字 0 則正常顯示。

大題數及應到／實到／缺考只接受非負整數，空白不等於 0。人數以**最近手動修改的兩欄**計算第三欄，編輯順序一併儲存；例如應到60、實到58會得到缺考2，再改缺考3，便以實到58＋缺考3重算應到61。若實到或缺考大於應到，會提示錯誤並阻止套用，不產生負數。

所有設定只保存在該瀏覽器的 localStorage，老師、人數與考場不會寫回 GitHub。切換裝置可使用預存考試代碼或匯出／匯入。

## 考前預存與6碼載入

到教室不用貼上長連結，只需輸入6碼考試代碼。

1. 考前在自己的電腦設定考試，按「套用設定」。
2. 打開「考試資訊 → 畫面與儲存 → 預存考試」，記下產生的6碼代碼。
3. 按「到 GitHub 儲存」，登入 GitHub 後按 **Commit changes**，將已填好的考試檔存進 main 分支。
4. 回到計時器按「確認已發布」。顯示「已可在考場使用」後，這組代碼便可使用；發布尚未完成時，稍後再確認。
5. 到教室打開網站，按上方「載入考試」，手動輸入6碼後載入。教室端不需要登入GitHub。

英文字母不分大小寫，輸入時可加空格或連字號；產生的代碼不包含容易混淆的I、O、1、0。完整短網址也只在原網站後加上7個字元，例如 `#A7K2M9`。可輸入 `SAMPLE` 載入清楚標示的示範考試。

每組代碼對應 `exams/代碼.json`，保存該次預存的全部考試資訊、時程、規則、強調、人數及畫面選項。修改內容後請重新預存一組；原有考試檔會保留。設定過長時，網站會提供「下載考試檔」，再到GitHub的exams資料夾上傳並儲存。

載入時使用即時時間，模擬狀態不會帶過去。現場調整並套用後，會移除網址中的代碼，重新整理沿用本機調整；再次開啟保存的代碼網址，則載入原先預存的內容。

預存與載入代碼需要網路，使用GitHub Pages提供的靜態JSON，不需要新增儲存服務、後端或在網頁放入登入憑證。未輸入代碼時，原本的單檔離線功能照常使用；斷網備援仍可匯出／匯入設定。

## 現場使用

1. 開啟 `index.html`，右上角 **⚙** 填入班別、考場、日期及考試資訊，按「套用設定」。
2. 確認電腦時間正確。畫面使用電腦時鐘並固定換算為 **UTC+8（台灣時間）**，沒有網路校時；電腦時區不同也不影響顯示。
3. 點 **⛶** 或按 **F** 進入全螢幕，按 Esc 離開。若瀏覽器限制網頁全螢幕，可使用瀏覽器自己的全螢幕功能。
4. 「模擬測試」可指定時間、暫停、1 / 10 / 60 倍速，或跳到各節點。**黃色橫幅代表模擬中**；按「回到即時」結束。重新整理永遠回到即時。
5. 考試前建議下載 `offline.html`，並匯出設定 JSON；斷網時直接開啟離線檔、匯入設定、套用即可。

### 自由管理時間節點

「時間調整 → 時間節點 → ＋ 新增時間節點」可新增、改名、修改或刪除節點，最多 40 個。可選擇相對入場、開始或結束，並填入正負分鐘；相對入場的節點不隨開考時間平移。入場、開始、結束保留為上方的基本計時欄位。

自訂節點會出現在時間軸標記、下方時間標籤、模擬跳轉與規則／階段的時間選單。每個節點旁會顯示文字引用代碼，例如 `{item-...}`，可直接複製到規則文案中。只有時間節點不會自動新增階段或公告；需要切換規則時，在「規則與階段」新增階段，將開始基準選為該節點即可。

遲到、可交卷、半小時與最後階段這四個預設節點也能刪除。刪除時會一併移除引用該節點的階段、規則與定時提醒，按套用後才生效。刪除可交卷節點後，開考後倒數改為距離結束；刪除最後階段節點後，不再顯示最後階段提醒或專注姿態。可透過取消放棄草稿，或恢復預設。

## 須知與階段

- 右側只有一張卡片，上半部固定規則不參與自動捲動；自訂固定規則過多時，可在固定區手動捲動。
- 手機及計算機規則由入場起顯示；舉手及廁所規則由開考起顯示。全部在結束時停止顯示。
- 階段文案已依定稿保留，修正為「姓名、學號及班級」，結束時要求學生等待助教清點後離場，該句預設強調。
- 入場準備最上方有淡杏色醒目提醒：「考試開始前，請勿翻閱試卷內頁或提前作答，僅可閱讀封面說明。請等候監考人員宣布開始。」它隨目前設定的開始時間自動隱藏；開考延後時也會連動。可在「規則與階段 → 入場準備」直接編輯或刪除。
- 最後階段的「暫停提前交卷，請等候考試結束後統一收卷」是一般規則。若現場不需要這項要求，直接刪除該條即可。
- 階段、規則與定時提醒可新增、刪除、修改；階段依時間排序，規則可上移／下移。至少保留一個於結束時間啟動的階段，避免結束後繼續顯示作答狀態。
- 每個階段可直接新增、編輯、刪除規則，以及上移／下移排序；另有「強調這條規則」勾選框，以柔和杏色底凸顯。Exam、Quiz 最後五分鐘的停收卷規則預設強調。未加入單條啟用或顯示條件等額外邏輯；不需要的條文直接刪除。
- 遲到、剩餘時間及最後五分鐘提醒均使用定時橫幅，預設顯示 **2 分鐘**，無音效、不彈出視窗；可調整文案、時長或關閉。背景分頁恢復後直接依現在時間重算，不重播已錯過的提醒。
- 階段文案超出可見區域時，以每秒 14 像素緩慢循環上捲，頭尾停留。滑鼠移入、鍵盤焦點、手動捲動會暫停；也有暫停按鈕。尊重系統「減少動畫」偏好，可手動啟用。
- 入場前顯示「等候入場」。考前倒數至開考，開始後倒數至可交卷，之後倒數至結束。時間軸依實際比例繪製，保留開始／可交卷／結束，已移除底部重複的入場與最後五分鐘小字。小螢幕放不下含秒標籤時會自動錯開。

### 動態時間文字

請使用以下代碼引用時間，避免直接輸入不會連動的 `09:40`：

| 代碼 | 內容 |
|---|---|
| `{admission}`、`{start}`、`{late}` | 入場、開始、遲到提示時間 |
| `{handin}`、`{half}`、`{final}`、`{end}` | 交卷、剩餘時間提醒、最後階段、結束時間 |
| `{finalMinutes}`、`{halfMinutes}` | 最後階段／提醒距離結束的分鐘數 |
| `{date}` | 考試日期 |

例：`{handin} 後才可以交卷。`、`考試剩下最後 {finalMinutes} 分鐘。`。預設文案皆已使用代碼。自訂內容一律視為純文字，不執行 HTML。

最後五分鐘的「考試剩下最後 {finalMinutes} 分鐘。」為定時提醒橫幅，可在「定時提醒」編輯、刪除或調整顯示時長。停止提前交卷仍是強調的一般階段規則。新版本只將舊設定中完全相同的預設倒數句移至提醒；已自訂或刪除的文字不會強制重建。Quiz 的原預設「隨堂測驗」會改為「小考」，並移除原預設清點後離場句，自訂名稱／文案保留。

## 儲存與離線

2026/10/31 更新會自動升級舊設定：原預設名稱「微積分一」改成「微積分1」，加入入場提醒及吉祥物設定；自訂名稱、班別、考場、時程與其他規則保留。升級只進行一次，新提醒經手動修改或刪除後不會重新加回。已刪除整個入場階段的設定不會被強制重建。舊 JSON 匯入也適用相同升級規則。

按「套用設定」後以 `localStorage` 儲存，鍵名為 `calculus-exam-timer.v1`。取消、關閉設定或按 Esc 會放棄草稿。模擬時間不儲存。瀏覽器限制儲存或設定毀損時，頁面會提示並安全載入預設；請使用匯出／匯入備份設定。

`index.html` 與 `offline.html` 是同一份完整單檔；不需要旁邊有 `src/`。檔案位置、不同瀏覽器與 GitHub Pages 網址之間可能不共用設定。匯出會下載**已套用**的設定；匯入先載入草稿，檢查後再按套用。設定不會上傳或同步到其他裝置。

GitHub Pages 首次載入需要網路，且本專案不使用 Service Worker。已開啟的頁面可繼續離線執行；要保證斷網後仍能重新開啟，請用事先下載的 `offline.html`。避免在監考中讓電腦睡眠。

## 吉祥物與動畫

使用依使用者正式設計圖製作的透明角色素材：黑色蓬鬆頭髮與翹毛、藍色帽T、大頭小身體、粉紅臉頰與豆豆眼。角色本身使用圖片保留手繪風格；SVG / CSS / JavaScript 負責分層、眨眼、裝飾與翻頁。沒有把整張含文字的設計圖放到網站。

| 階段 | 姿態與動畫 |
|---|---|
| 等候／入場準備 | 趴桌看前方，偶爾眨眼；和每次隨機6–10秒的閉眼小睡交替。清醒時對話泡泡的點點輕跳，睡覺時 Zzz 淡入並向上飄。 |
| 尚不可交卷 | 坐直閱讀、眨眼、微小呼吸；每次翻一頁，完成後隨機休息4–10秒。 |
| 可以交卷 | 保持閱讀，以放鬆的小微笑與眨眼、翻頁呈現。 |
| 最後階段 | 認真表情、眨眼、呼吸，繼續隨機翻頁。 |
| 考試結束 | 闔書微笑，獨立手臂圖層繞肩膀小幅揮動，不附加文字。 |

五個姿態共用相同尺寸、對齊人物與桌面位置，以360毫秒交疊淡入淡出切換。只平移／旋轉完整圖層，不縮放五官或扭曲身體。揮手的手臂位於完整身體圖層後方，避免露出裁切接縫或穿過書本、身體。

書本封面朝觀眾，紙頁面向角色。單張活動紙頁以書脊為軸，從畫面右側翻至左側（約1.1秒），落下後隱藏，再重置；不會來回翻動。單一 timeout 在每次完成後重新抽取4–10秒間隔。切換至等待或結束、隱藏角色、關閉動畫、背景分頁或減少動畫時，會取消翻頁。

「考試資訊 → 吉祥物」可勾選角色或播放動畫；關閉動畫保留靜態插畫。`prefers-reduced-motion: reduce` 會停用呼吸、眨眼、睡眠、點點、Zzz、翻頁、揮手與切換淡化。設定沿用原本的儲存欄位。

八張生產素材只各內嵌一次於每份HTML，SVG引用共用影像。兩份產出檔各約3MB，無須外部資源。素材與製作提示詞在 `src/assets/mascot/ASSET-NOTES.md`、`ANIMATION-NOTES.md`；原始全身結束圖亦保留作設計參考。

左上書籤與四角星、右側鉛筆時鐘及其餘UI保留。標題仍為「微積分1 期中考試」。

## 開發與測試

使用 Node.js 18 以上；**無第三方相依套件，不用 npm install**。

```sh
npm run build
npm test
npm start
```

預覽網址 `http://127.0.0.1:4173`。關閉伺服器按 Ctrl+C。

2. 開考 +10 分鐘，檢查入場不動、交卷與結束平移；再試額外延長。
3. 確認最後階段是否暫停提前交卷，是否符合現場老師指示。
4. 加入較長階段內容，確認自動上捲與暫停；檢查投影機實際字體大小。
5. 匯出設定，開啟離線檔並匯入。正式使用前按「回到即時」，核對電腦時間。
