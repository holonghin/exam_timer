# 角色素材製作紀錄

使用內建 imagegen 工具，依使用者提供的五階段角色參考圖製作。沒有將整張設計圖、文字或欄位放入網站。每個素材均為同尺寸透明 RGBA 圖片，網頁素材以 512 × 512 保存；建置時內嵌於 HTML。原始生成圖保留於 Codex 的 generated_images 目錄。

角色造型：黑色蓬鬆頭髮與翹毛、藍色帽T、大頭小身體、粉紅臉頰、豆豆眼、柔和手繪筆觸。

生產素材位置：`src/assets/mascot/`。等待／閱讀／放鬆／專注／結束五個姿勢，另有閱讀眨眼、等待閉眼兩個圖層。動畫只移動分層、透明度及單張紙頁，不縮放五官或變形身體。
